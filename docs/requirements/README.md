# Wandrr Functional Requirements

This directory contains the canonical, cleaned functional requirements for Wandrr.

The legacy root `requirements.md` is intentionally preserved for historical reference and migration context. New and updated product requirements should be added here.

## Writing Rules

- Each requirement has exactly one unique identifier in the form `REQ_<PAGE>_<NUMBER>`.
- Each requirement belongs to exactly one Path.
- Each requirement describes one observable user-facing behaviour or business rule.
- Requirements are listed under hierarchical sections and sub-sections, not in tables.
- Requirements describe visible information, user actions, navigation, validation, empty states, loading states, error states, and responsive differences only when behaviour differs.
- Requirements focus only on user-observable product behaviour.
- IDs must not be reused or renumbered after publication.
